# ver2 통합본 검증 — 2026-10-01

`ver2`는 원격 `main`의 `2feb2eb1347a6806a2879429667f40e020c46208`을 기반으로 구성했다. 원본 로컬 작업 폴더와 개인 초안은 보존하고 별도 작업 폴더에서 공개 코드를 통합했다.

## 포함한 변경

- 승인된 관광 출처 등록부, 기존 수집기와 CSV 정제, 원자적 PostgreSQL snapshot 발행.

- 출처·미확정 상태·유지 장소 선택 화면 및 품질 리뷰에서 확인한 네 가지 문제의 수정과 회귀 테스트.
- 관광 스키마·OpenAPI·DBML·사용 안내와 CI의 Python 테스트.

원격 main의 가입 확인, 초대 링크 재진입, 이름을 포함한 여행 URL, 기본 교통수단 표시와 Google Maps 대중교통 링크, Actions v5와 서식 수정을 유지했다. 원격에서 이미 정리한 파일을 이전 로컬 버전으로 되돌리지 않았다.
