## 브라우저 검증

서로 다른 두 브라우저 컨텍스트에서 추천 숨김·재표시/새로고침 복원, 장소 예산 저장,
공동 체크리스트, 초대 링크 수락, 공유 메모, 채팅 수신, 정산 금액, 초대 수락 알림,
비밀번호 확인 탈퇴까지 확인했다. 390px 모바일에서 가로 넘침이 없음을 검사하고
데스크톱·모바일 스크린샷을 시각 확인했다.

신규 공동 여행 UI 테스트는 외부 지도 로딩을 차단해 기본 지역지도 상태에서 검증한다.
별도 기존 Google 실연동 및 Places 실연동 테스트는 전체 회귀 실행에서 통과했다.

## 동작 범위

- 채팅은 열린 패널에서 6초 폴링, 알림과 일정 변경 감지는 15초 폴링이다.
- 일정 변경 감지는 갱신 안내를 보여주며, 작성 중인 메모를 자동 덮어쓰지 않는다.
- 체크리스트·정산은 저장 후 재조회와 명시적 새로고침을 지원한다.
- 초대는 서비스 알림함으로 전달된다. SMTP 이메일 발송·송금 실행·환율 자동 환산은 제공하지 않는다.
- 링크는 현재 접속한 서비스 주소로 만들어진다. 다른 기기와 공유하려면 접근 가능한 배포 주소에서 생성해야 한다.
- 로컬 DB 마이그레이션을 적용했으며 AWS 배포는 이번 작업 범위에 포함하지 않았다.
