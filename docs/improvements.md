## 만들어내지 않은 정보

- 요즘 인기 / 최근 관심 증가 / 리뷰 증가량: 시계열 데이터가 없으므로 구현하지 않았습니다.
- 현지인 / 숨은 맛집: 제공된 리뷰 언어 표본만으로 확정하지 않습니다. 한국어 우선 조회는 표본 언어 편향도 있습니다.
- 실제 개화·단풍·라벤더 시즌 / 계절별 개방일: 검증된 운영 데이터가 없어 표시하지 않습니다. '계절 취향'은 태그 기반 후보입니다.
- 일정 사이 남는 시간에 들를 수 있는지: 방문 소요시간과 교통의 확정 정보가 없어 '마지막 장소 주변 20km 직선 후보'까지만 제공합니다.
- 일본어 장소명 20,810개 전체 번역: 하지 않습니다. 한국어 원천이 있는 데이터 또는 Google에서 한국어로 반환한 상세만 사용합니다.
- 교통비: 신뢰할 수 있는 요금 원천 없이 숫자를 추정하지 않습니다.

## 데이터·서비스 운영

- 장소·일정 DB는 보존했고 테스트는 전용 계정과 해당 일정만 정리합니다.
- Google 사진·리뷰·추가 상세는 PostgreSQL에 적재하지 않습니다. 출처/작성자/원문 링크/번역 여부를 화면에 표시합니다.
- 사진은 10분 유효한 서명 참조로 요청하며 API 키는 브라우저 URL에 포함하지 않습니다.
- OSM 경로는 1.1초 간격 제한, 좌표·교통수단별 15분 메모리 캐시(최대 200건). 공개 데모는 가용성 보장이 없으므로 배포용 자체/계약 서버 필요.
- 회원용 장소 조회 자체와 별개로 외부 보강은 인증·요청 횟수 제한을 적용합니다.
- /terms, /privacy에 개인 학습용 운영과 외부 데이터 흐름을 안내합니다. 상업 서비스의 완결된 법률 문서가 아닙니다.

## 검증 근거

- 단위/REST: 31개. 날짜·입력·권한·실제 DB·추천 제외·리뷰 언어·OSRM·위조 사진 토큰 검사.
- Chrome: 6개. 기본 여행 흐름, 계속 탐색, 추천 이유, 알림 X, 지도 도시명, 실제 지도/경로/날씨, 실제 Places 한국어/사진/리뷰.
- 실제 외부 응답: improvements-live-check.json, places-browser-check.json, google-browser-check.json.
- 최초 브라우저 검사는 이전 REST 서버가 남아 새 날짜 요청과 OSM 응답이 반영되지 않아 실패했습니다. 대상 프로세스를 확인해 새 서버로 교체한 후 재검증했습니다.
- Places 활성화 전에는 SERVICE_DISABLED를 확인했고, 사용자 활성화 후 HTTP 200과 실제 사진 로딩을 검증했습니다.
