# 관리자 기능

> 이전 구현·발표 시점의 기록입니다. 현재 동작·저장 계약은 [README](../README.md), [v2 검증 기록](quality-v2.md), [OpenAPI](Bookhaedo-API.yml)를 기준으로 확인해주세요. 기록 당시 화면 캡처는 소스 저장소에 포함하지 않습니다.

- `/admin`: 회원 검색·20명 단위 페이지 이동, 회원/관리자 권한 변경, 정상/이용정지 변경, 최근 변경 100건.
- 관리자도 기존 회원의 여행 기능을 이용할 수 있다. 다른 회원의 여행 내용은 조회·수정할 수 없다.
- 서버가 매 요청마다 DB의 현재 역할·상태를 검사한다. 일반 회원의 관리자 API 호출은 403, 미인증은 401.
- 자기 권한·상태 변경 금지. 변경은 트랜잭션과 감사 기록으로 저장하고 대상 계정의 세션을 만료한다.
- 기존 회원은 모두 MEMBER/ACTIVE로 유지. 공개 회원가입으로 ADMIN을 지정할 수 없다.
- 최초 관리자는 운영자가 `npx tsx scripts/grant-admin.ts <기존 가입 이메일>`로 명시적으로 지정한다. 공용 관리자 암호나 기본 관리자 계정은 만들지 않는다.
- 원본 서버 코드 편집, 임의 SQL 실행, 회원 영구 삭제, 장소명·지역·테마 기준정보 수정은 제공하지 않는다.

## 액터
회원: 탐색·개인 여행 관리. 관리자: 회원 기능 + 회원 권한/상태 관리·감사 이력 조회. 외부 지도·여행정보 시스템: 지도·경로·날씨·장소 상세정보 제공.
