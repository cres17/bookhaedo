# 2026-09-28 코드 통합·공개 검증

최신 원격 main `d38f3e3`에 로컬의 화면·서버 구조 개선, 제공자 캐시, 데이터 무결성, 운영 도구를 병합했다. 이 문서는 해당 병합본에서 실제로 실행한 검사 기록이다. 운영 서버 배포나 새로운 전후 성능 비교는 수행하지 않았다.

## 포함한 변경

- 서버 인증·HTTP·라우터·관측 모듈 분리, 프런트 라우터·여행 도구·동기화 로직 분리.
- 상단 홋카이도 안내, 12개 지역 사계절 안내, 일정 시간표, 공동·개인 지출과 내보내기.
- 날씨·경로·장소 ID 재사용, 동시 중복 요청 합치기와 제한된 병렬 처리.
- 버전·체크섬 마이그레이션, 중앙 요청 제한, 구조화 로그·Prometheus 지표, 백업·격리 복원·부하 검사 도구.
- 원격에 먼저 반영된 회원가입 비밀번호 재확인, 초대 링크 재진입, 여행 이름 URL, 기본 이동수단 표시와 Google Maps 대중교통 링크 보존.

리팩터링으로 이동한 라우터에 원격의 `google=drive` 옵션을 반영했고, 초대 화면의 새로운 디자인에서도 이미 참여한 여행으로 재진입하는 동작을 유지했다.

브라우저 검사에는 실제 지도·Open-Meteo 날씨·Valhalla 경로·Places 상세 연동과, 로그인·초대·일정·정산·지역 안내·모바일 회귀가 포함된다. 악천후 분기와 저장 검증에는 통제된 제공자 응답을 사용하는 테스트도 포함되므로 모든 브라우저 검사를 실제 악천후 실험으로 해석하지 않는다.

백업 최초 시도는 로컬 기본 `pg_dump` 14와 DB 서버 17의 버전 차이로 중단됐다. 설치된 PostgreSQL 17 도구를 명시해 다시 실행했고, 20,810개 장소를 포함한 백업의 체크섬·행 수·이력을 격리 복원 DB와 대조했다. 원본 DB를 덮어쓰지 않았고 덤프는 공개 파일에 포함하지 않았다.

## 성능 수치와 운영 범위

이번 부하 검사는 `/api/regions`의 중앙 요청 제한과 카탈로그 조회를 통과하는 로컬 검사다. 전체 사용자 여정, 실제 외부 제공자를 호출하는 동시 부하, 클라우드 처리량·p95·SLA를 검증한 것은 아니다.

README의 38.58%·48.64%·14.40%와 [외부 API 측정 원본](benchmarks/provider-measurement-20260922.json)은 **2026-09-22 작업본의 전후 비교**다. 이번 병합본을 재측정한 결과와 혼합하지 않는다. [날씨 제공자 교체와 호출 최적화](weather-provider-and-performance.md)에 구현·검증 경계를 설명했다.

운영 인프라의 중앙 로그·경보 수신, 장시간 부하, RDS 장애조치와 리전 외 복원, 비밀 회전·관리자 강화 인증 등은 별도 운영 검증이 필요하다. 위 통과 결과만으로 엔터프라이즈 운영 준비 완료를 주장하지 않는다.

## 공개 파일 범위

소스·마이그레이션·API 명세·테스트·운영 예시·설계 문서와 검토한 측정 JSON을 포함한다. 실제 `.env`, 비밀키, 사용자 DB 덤프, 원본 데이터셋, 실행 로그·화면 캡처, 빌드 결과·의존성 폴더, 개인용 E04 작성 자료는 제외한다. `.env.example`은 개발용 기본값과 빈 비밀값을 담은 설정 예시로 유지한다.
