# 발견하기 통합 검색

> 이전 구현·발표 시점의 기록입니다. 현재 동작·저장 계약은 [README](../README.md), [v2 검증 기록](quality-v2.md), [OpenAPI](Bookhaedo-API.yml)를 기준으로 확인해주세요. 기록 당시 화면 캡처는 소스 저장소에 포함하지 않습니다.

‘다시 추천 / 일반 검색으로’ 전환 버튼만 제거했습니다. ‘마음이 가는 장면’ 테마 카드와 전체·추천·가볼 곳·먹을 곳·머물 곳 탭은 유지합니다. `/api/places?q=삿포로 공원`처럼 지역과 유형을 함께 입력합니다. 지도·페이지 이동·이전 탐색 복원은 유지합니다. 검색 제출은 `/api/places`, 테마 선택은 `/api/discover`를 호출합니다. 두 API 모두 지역+유형+잔여 키워드를 해석합니다. 추천 탭은 선택 테마가 없으면 자연 테마를 사용하며, 추천 후보는 최대 40개를 받아 12개씩 표시합니다.

- 지역: 기존 12개 관광권의 한국어·일본어 명칭, 지역 코드. 입력한 지역이 드롭다운 선택보다 우선합니다.
- 유형: 공원, 놀거리, 양식, 일식, 카페, 온천, 박물관/미술관, 음식점, 숙소.
- 남은 단어: 한국어/일본어/영문 이름 및 시정촌명 검색. 예: 삿포로 공원 오도리.
- 지역 AND 유형 AND 나머지 이름을 적용합니다. 여러 지역 또는 여러 유형은 각 그룹 안에서 OR로 검색합니다.
- 공원은 leisure, 놀거리는 tourism/leisure, 음식 유형은 cuisine 태그로 판별합니다. 온천은 온천 태그 또는 일본어 이름의 温泉을 사용합니다. 일식은 일본 소재 여부가 아니라 요리 태그로 판별합니다.
- 분류 태그 없는 장소는 분류 검색에서 누락될 수 있습니다. 실시간 영업/인기/안전 확인이나 AI 자연어 추론이 아닙니다. 지역은 기존 관광권 기준이므로 비에이는 아사히카와·비에이 범위에 포함됩니다.
- 응답의 filters는 적용 지역 코드·유형 이름·잔여 키워드, notice는 분류 데이터 한계를 제공합니다.
- 검색 결과는 같은 이름이 3곳 이상 반복되는 프랜차이즈를 관광권당 대표 1곳으로 축약합니다. 그 외 장소는 같은 이름이면서 약 100m 위치 구간까지 겹칠 때만 하나로 표시합니다. 원본 장소 행은 삭제하지 않습니다.
