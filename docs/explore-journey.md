# 지역별 탐색 화면 개선 — 2026-09-08

> 이전 구현·발표 시점의 기록입니다. 현재 동작·저장 계약은 [README](../README.md), [v2 검증 기록](quality-v2.md), [OpenAPI](Bookhaedo-API.yml)를 기준으로 확인해주세요. 기록 당시 화면 캡처는 소스 저장소에 포함하지 않습니다.

지역 소개 → 테마 → 장소 목록을 왼쪽 패널에 배치하고 오른쪽 지도 인스턴스를 유지합니다. 모바일은 지도 상단 고정 영역 + 하단 탐색 패널 스크롤입니다.

- 12개 관광권별 짧은 소개, 분위기 문구, 태그. 소개 문구는 서비스 편집 콘텐츠이며 실시간 개방/운영 정보가 아닙니다.
- 지역 선택, 이전/다음 지역, 수평 스와이프. 소개·선택 지역·지도 중심·API 조건이 함께 갱신됩니다.
- 테마와 분류별 장소 탐색. 일반 검색은 GET /api/places?limit=12&offset=...으로 서버 페이지 조회.
- 추천은 기존 GET /api/discover의 최대 40개 후보를 받아 12개씩 표시. 전체 후보 건수와 이번에 받은 건수를 구분합니다.
- 지도에는 현재 페이지의 장소만 표시. 상세 화면 이동 후 탐색 복귀 시 지역·테마·검색·분류·페이지·패널 스크롤·지도 위치/배율을 메모리에서 복원합니다. 브라우저 완전 새로고침까지 유지하는 영구 저장 기능은 아닙니다.
- AbortController와 요청 순번으로 늦은 응답을 무시합니다. 로딩/실패 시 이전 결과 마커는 제거합니다. 퇴장 애니메이션 중 카드 클릭을 막습니다.
- 현재 위치 탐색은 명시적 권한 동작으로만 수행. 권한 거절·지역 밖 좌표·뒤늦은 위치 응답을 처리합니다.
- 소개 카드와 메인 화면에 캔버스 눈 효과: 거리별 입자 크기/속도/투명도, 바람, 포인터 주변 흐름, 일시정지. reduced-motion 및 비활성/화면 밖에서는 애니메이션 정지, 이벤트·프레임 정리.
- 새 서버 API나 DB 구조 변경 없음.

검증: production build 통과, 기존 단위/REST 44개 통과, 기존 브라우저 7개 통과, 새 탐색 브라우저 2개 통과. 신규 검증은 실제 DB 장소의 페이지 조회와 복원, 실제 지도 표시, 테마 API, 지도 영역 유지, 모바일 가로 넘침, 모션 설정, 지연 응답·503 복구를 포함합니다. 지연/503만 테스트에서 주입했습니다.
