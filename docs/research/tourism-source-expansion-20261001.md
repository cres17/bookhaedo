# 지역 관광 자료 확대 (2026-10-01)

북토시 시설 자료 10건을 하코다테 앱 지역에 추가했다. 북토시를 하코다테 시의 행정자료로 표시하지 않으며 제공 기관은 `北斗市`로 유지한다. 후라노·신치토세 2개 앱 지역에서 하코다테를 포함한 3개 지역, 승인 출처는 3 → 4개다. 나머지 9개 지역의 자료를 확보한 것은 아니다.

## 라이선스와 수집 조건

[북토시 HARP 데이터셋](https://www.harp.lg.jp/opendata/dataset/1657.html)은 2026-08-26 갱신 CSV에 CC BY를 표시한다. [HARP 이용규약 제1조](https://www.harp.lg.jp/opendata/terms.html)는 별도 리소스 라이선스가 없으면 CC BY 4.0을 적용한다. 별도 조건이 표시된 이미지·제3자 자료는 가져오지 않고 시설 설명·명칭·좌표만 정제했다. 서비스 응답에 제공 기관·원문·라이선스·정제/발췌 안내를 유지한다.

robots 원문은 `User-agent: *`, `Crawl-delay: 60`이었다. 기존 상태 디렉터리와 도메인 간격을 재사용해 robots·목록·CSV 요청 시작 간격 60.004초 이상을 지켰다. 단일 최신 CSV URL을 등록부에 고정하고, 구버전 CSV나 URL 변경은 자동 발행하지 않도록 collector·normalize·publish에서 확인한다. 리다이렉트·도메인·2MB·스키마·ID 중복·좌표 검증도 유지한다.

## 실제 결과와 한계

- 수집: cp932, 유효 시설 10건, 좌표 10건. 마지막 빈 행은 기존 빈 행 처리로 제외했다. 모든 필수 열은 기존 정제 규칙과 일치해 별도 열 추론은 하지 않았다.
- 연결: 2/10(20%). `松前藩戸切地陣屋跡`, `八郎沼公園`만 exact-name·같은 지역·250m 유일 후보로 연결됐다. 7건은 명칭 불일치, 1건은 같은 이름 catalog가 약 410m 떨어져 연결하지 않았다. 기존 catalog를 이동하거나 별칭을 추측하지 않았다.
- 발행: snapshot `b61d1e88-eb51-4be5-a673-693efb2a45fb`. 활성 자료는 시설 34건·행사 13건 = 47건, 누적 record는 이전 버전 보존으로 71건이다. catalog는 20,810개다.
